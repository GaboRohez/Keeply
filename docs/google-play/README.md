# Paquete de publicación de Google Play

Contenido preparado para la versión 1.0:

- `store-listing-es.md`: ficha principal en español (México).
- `store-listing-en.md`: traducción opcional; consultar la nota de categorías del informe QA.
- `data-safety.md`: respuestas sugeridas para Seguridad de los datos.
- `privacy-policy.html`: página lista para alojar, con correo pendiente de reemplazo.
- `release-checklist.md`: pasos restantes en cuenta, políticas, binario y dispositivo físico.
- `assets/branding/play-icon-512.png`: ícono 512 × 512, 205 KB, con alfa.
- `assets/branding/feature-graphic-1024x500.png`: gráfico 1024 × 500, 493 KB, sin alfa.
- `assets/branding/PROMPTS.md`: prompts y decisiones usados para generar la identidad visual.
- `assets/screenshots/promo/*.jpg`: seis piezas promocionales JPEG 1080 × 1920, 9:16 y sin alfa,
  con beneficio breve y una captura real enmarcada; son las recomendadas para subir.
- `assets/screenshots/promo/promo-preview.jpg`: vista conjunta para revisar el carrusel completo.
- `assets/screenshots/play/`: versiones limpias sin texto promocional.
- `assets/screenshots/final/`: PNG completos 1080 × 2400 conservados como evidencia QA.

La ficha cumple los límites revisados: nombre de 6/30 caracteres, descripción corta ES de 70/80,
EN de 66/80 y descripciones completas por debajo de 4000 caracteres.

No publicar el AAB actual sin completar la firma y los elementos marcados como pendientes en
`release-checklist.md`.
